# Arduino Railway Crossing 

## Overview
An Arduino-based railway crossing simulation featuring LED traffic lights, an automated barrier, push-button controls, and a digital timer.

## Features
- Traffic light control (red, yellow, and green LEDs)
- Automated barrier movement
- Push-button control for train arrival and departure
- Digital timer to track system states

## Technologies
- Arduino
- C/C++
- Embedded Systems
- Electronics

## Purpose
This project demonstrates basic embedded programming, electronic circuit design, and automation using Arduino.
